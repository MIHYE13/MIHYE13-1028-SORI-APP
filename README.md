# 소리책방

교사가 PDF·이미지 교재로 차시를 만들고, 학생이 교과서를 소리 내어 읽은 뒤 손글씨 또는 키보드로 문제를 푸는 정적 웹앱입니다.

## 현재 구현

### 비용 정책

- 생성형 AI API를 사용하지 않아 앱 자체의 API 크레딧 비용은 없습니다.
- 문제 생성·채점·퍼즐은 브라우저에서 실행됩니다.
- PDF와 OCR 모듈은 실제 사용할 때만 내려받습니다.
- OCR 언어 모델은 연속 작업에서 재사용하고 2분 동안 사용하지 않으면 메모리에서 해제합니다.
- PDF는 기본 1~12쪽만 처리하며 교사가 범위를 바꿀 수 있습니다.

- 5학년 과학 `3. 열과 우리 생활` 62~63쪽 샘플 차시
- 반·번호와 가명 ID를 이용한 학생 시작 화면
- Web Speech API 낭독 인식과 70% 통과 기준
- 70% 미만일 때 한 번 더 읽은 뒤 문제 풀이 허용
- 객관식·단답형·서술형 문제
- 교과서 그림 2×2·2×3·3×3 이미지 퍼즐
- 퍼즐 조각 드래그·클릭 교환·키보드 조작
- 퍼즐 이동·힌트·다시 섞기 횟수 JSON 기록
- 마우스·손가락·펜 손글씨 캔버스
- Tesseract.js 한국어 OCR과 학생 수정
- 키보드 답안 입력 대안
- 핵심어·문자열 유사도 기반 형성평가 피드백
- 선택적 문제 화면 포인터 기록
- 결과 JSON 다운로드·복사
- 교사용 PDF·이미지 텍스트 추출 및 문제 초안 생성
- 교사 검토 후 수업 ZIP 내보내기
- GitHub Pages 배포 워크플로

## 실행

```powershell
npm install
npm run dev
```

프로덕션 빌드와 테스트:

```powershell
npm test
npm run build
```

## 간단판 (HTML 한 파일)

- 경로: `/simple/` (특정 수업은 `/simple/?lesson={lesson-id}`)
- 파일: `public/simple/index.html` — 빌드·라이브러리 없이 학생 핵심 흐름만 제공
- 설계: [SIMPLE_WEBAPP_DESIGN.md](SIMPLE_WEBAPP_DESIGN.md)

## 교사용 제작실

- 경로: `/#/teacher`
- 초기 데모 비밀번호: `teacher`
- 이 비밀번호는 화면 구분용이며 실제 인증 기능이 아닙니다.

교재를 선택하고 텍스트를 확인한 뒤 문제 초안을 생성합니다. JPG·PNG 그림을 선택하면 이미지 퍼즐 문제도 추가할 수 있습니다. 모든 문제를 교사가 승인하고 자료 배포 권한을 확인해야 ZIP을 내려받을 수 있습니다.

## 새 차시 추가

1. 원본은 프로젝트의 `교과서_원본/{차시}`에 둡니다. 이 폴더는 `.gitignore`에 포함되어 공개 저장소에 올라가지 않습니다.
2. 교사용 제작실에서 PDF·JPG·PNG를 직접 선택합니다.
3. 추출된 본문과 문제를 검토하고 수업 패키지를 내려받습니다.
   - 퍼즐 문제는 JPG·PNG 이미지, 대체 설명, 2×2·2×3·3×3 난이도를 지정합니다.
4. ZIP의 내용을 `public/lessons/{lesson-id}`에 넣습니다.
5. `public/lessons/index.json`에 게시할 수업을 추가합니다.
6. 테스트와 빌드를 실행한 뒤 GitHub에 커밋합니다.

이전 차시를 덮어쓰지 말고 새 `lessonId`를 사용합니다. 같은 차시를 수정할 때는 `lessonVersion`을 올립니다.

## GitHub Pages

저장소의 기본 브랜치를 `main`으로 만들고 GitHub의 **Settings → Pages → Source**를 **GitHub Actions**로 설정합니다. `main`에 푸시하면 테스트와 빌드 후 `.github/workflows/deploy.yml`이 배포합니다.

## 중요한 제한

- 음성 인식은 실제 발음·억양 평가가 아니라 인식 문장과 원문의 일치율 추정입니다.
- 브라우저 제공자의 음성 서비스에서 음성이 처리될 수 있습니다.
- 한국어 자유 필기 OCR은 정확하지 않을 수 있어 학생 확인이 필수입니다.
- 이미지 퍼즐은 그림 관찰 활동이며 교과 개념 이해를 단독으로 평가하지 않습니다.
- 공개 GitHub Pages의 교재와 정답은 기술적으로 숨길 수 없습니다.
- 결과 JSON은 사용자가 수정할 수 있으므로 공식 시험·성적 인증에 사용하지 않습니다.
